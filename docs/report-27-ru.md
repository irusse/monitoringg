# Отчёт — фаза 27 RDM6300 в существующий ACL (13 октября 2026)

Продукт: **MESH 485 Extender**. Прогоны **25** и **26** сделаны. Фаза **27** — считыватель на ноде мониторинга, **сделана**. Живого модуля не было: проверка — байтовая фикстура.

Седьмого id в DISCOVER нет. Карта остаётся событием `TS-001`.

---

## Реализовано

| Что | Как |
|---|---|
| Кадр | `0x02`, 10 hex-символов (5 байт), 2 hex XOR этих байт, `0x03`. UID — эти 10 символов в верхнем регистре. |
| Ошибка | Чужая длина или неверная сумма увеличивает `rdm_err`. Это не карта и не событие. |
| Повтор | Тот же UID меньше чем через 2 с — одна запись. |
| ACL | Тот же `checkUid` / `noteCard`, что у Wiegand. Пустой список — `Denied`, `AccessGate` остаётся `LOCKED`. Карта из списка — импульс OPEN. Событие `source` `RFID`. |
| Образ монитора | `-D MESH485_NODE_ID=\"EXT-002\" -D MESH485_RDM6300=1`. UART1 RX = GPIO **38**, 9600 8N1. DE держится в RX, адаптеры шины не TX. Wiegand 15/16 в этом режиме не вооружается. |
| Образ панели | Без этого флага. UART1 по-прежнему RS-485, Wiegand на месте. |
| Игнор | `setRdmIgnore` — только локальный флаг. Потеря радио его не включает. |
| ПЦН | Хоп по-прежнему не открывает турникет и не двоит строку. |

GPIO 19/20 и фото в JSON не попадали.
