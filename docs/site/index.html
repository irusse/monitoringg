формула

Один узел. Три мира.

Android и Windows говорят на MESH 485. Heltec несёт MeshCore. На земле — пожарка, охрана, счётчики, ПЛК и СКУД.

Транспорт

BLE + USB Companion. OLED — продукт, не чат. GPIO 19/20 навсегда USB.

PROFILE_ACCESS

Wiegand 15/16, OPEN 40, лампы, E-STOP. ACL — фаза 17.

Консоль

Один Flutter на Android и Windows. Без контактов MeshCore.
