# Отчёт — фаза 25 сухой контакт ПЦН (13 октября 2026)

Продукт: **MESH 485 Extender**. Образ `heltec_v4_access`. Каскад **01–19 закрыт**. Фазы **20–23** сделаны. Фаза **25** — вход «Тревога» панели в EventStore ноды у панели, **сделана**.

Шесть DISCOVER: прежние `RAW-001` / `TS-001` / `PP-001` / `S10-001` / `S20-001` и новый `PCN-001`.

---

## Реализовано в фазе 25

| Что | Как в образе |
|---|---|
| Вход | GPIO **47**, `INPUT_PULLUP`, активный LOW. Разомкнутый вход — не тревога. |
| Дребезг | 50 мс. Короче — события нет. Удержание уровня вторую строку не пишет. |
| Событие | `device_id` `PCN-001`, `point_id` `ALARM`, `type` `PCN`, `source` `GPIO`. LOW → `state` `ALARM` / `severity` `ALARM`. HIGH → `state` `NORMAL` / `severity` `INFO`. Новый uuid и sequence на каждый фронт. |
| ACK | `device_ok` = 1 (уровень прочитан). `mesh_ok` = 0: на вторую ноду ещё не уходит. |
| Старт | Первый устойчивый уровень событием не становится. Разомкнутый вход → в `EVENT_LIST` нет `PCN`. |
| DISCOVER | `PCN-001`, протокол `PCN_CONTACT`, возможность только `READ_STATUS`. `COMMAND_EXECUTE` → `NO_PERMISSION`. |
| OLED | READY: `ТРЕВОГА` или `НОРМА` по последнему устойчивому уровню. Экрана чата нет. |
| Flutter | Существующий список «События» рисует `state`. Fixture содержит одну запись `PCN` / `ALARM`. |
| Орион | Кадр с верным CRC по-прежнему не становится `ALARM` сам по себе. |
| Заморозка | GPIO 19/20 не в JSON. Фото не в JSON. RS-485 39/38/26 этот прогон не занимает. `MeshCoreService::send` не чинился. |

Доставка на `EXT-002` — [`agent/prompts/26-pcn-mesh.md`](../agent/prompts/26-pcn-mesh.md).

### Проверки фазы 25

- Native: фронт → одно `ALARM`; удержание → без второй; отпуск → одно `NORMAL`; старт разомкнут → нет `PCN`; дребезг 20 мс молчит; CRC-кадр Сигнал-10 не `ALARM`.
- Path A / S10 / S20 / Access / AuthZ в том же `native_protocol_tests`.
- Flutter: плитка `PCN · PCN-001` показывает `state ALARM`.
