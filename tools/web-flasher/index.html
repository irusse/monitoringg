MESH 485 — прошивка Heltec

Chrome или Edge. Закройте монитор порта, иначе плата не откроется. Антенна должна быть на плате до включения передатчика.

Heltec WiFi LoRa 32 V4

USB-C, узел EXT-001. Считыватель RDM6300 и сирена уже в этом образе. Роль в меню платы сохраняется.

Heltec WiFi LoRa 32 V3 — приёмник

CP2102, узел EXT-002, роль приёмник, канал 1. Сирена на GPIO 48 при тревоге.

Heltec WiFi LoRa 32 V3 — источник

Узел EXT-003, роль источник. Чужой сигнал эту плату не включает.

Heltec T114

Этот образ на T114 не ставится. T114 — это nRF52840, а прошивка собрана под ESP32-S3. Кнопка прошивки для T114 здесь намеренно отсутствует: Web Serial и esptool пишут только ESP32. Для T114 нужна отдельная сборка под nRF52, её в этом репозитории нет.
